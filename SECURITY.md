# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within Sanitas, please follow the steps below:

1. **Do not disclose the vulnerability publicly**. Instead, please email the details to our security team at [anuragsingh6569201@gmail.com]. Include the following details:
   - A description of the vulnerability.
   - Steps to reproduce the vulnerability.
   - Any potential impacts.

2. **Provide sufficient detail** to allow us to understand and reproduce the vulnerability. The more detail you provide, the quicker we can address the issue.

3. **We will acknowledge receipt of your report** within 48 hours and will work with you to understand and resolve the issue as quickly as possible. We aim to resolve critical vulnerabilities within 7 days of disclosure.

4. **Once the vulnerability is resolved**, we will notify you and provide a public disclosure of the vulnerability along with the fix.

## Security Practices

To ensure the security of Sanitas, we follow these practices:

- **Code Review**: All code changes are reviewed by at least one other developer to identify potential security issues before merging.
- **Dependency Management**: We regularly update dependencies to the latest versions and monitor them for known vulnerabilities.
- **Penetration Testing**: We conduct periodic penetration tests to identify and mitigate potential security weaknesses.
- **Security Training**: Our development team receives regular training on secure coding practices and emerging security threats.
